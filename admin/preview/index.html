Environment — prod

Name
Value

Injected into app_api-prod at deploy time and read with System.getenv. REDIS_PASSWORD is also what the matching Redis enforces. KTOR_ENV, REDIS_HOST and REDIS_PORT come from the stack file and are refused here.

Saving redeploys both environments, because a stack deploy reconciles the whole stack. Live replica count and deployed image are preserved.

CI webhook — prod

POST
Endpoint
https://admin-aichat.acme.dev/hooks/deploy/app/prod
Deploy token — send as X-Deploy-Token
••••••••••••••••••••
Call it from your pipeline
curl -fsS -X POST https://admin-aichat.acme.dev/hooks/deploy/app/prod \ -H 'X-Deploy-Token: preview-token-not-real-000000' \ -H 'Content-Type: application/json' \ -d '{"image": "ghcr.io/you/app:sha-'"$GITHUB_SHA"'"}'
The update is graceful because of the service's own policy, not this endpoint: start-first brings the new task to healthy before stopping the old one, monitor: 90s gives the JVM time to boot before Swarm judges it, and a failure rolls back automatically. The call waits for that to finish and returns 502 if Swarm rolled the deploy back, so a bad image fails your pipeline instead of quietly reverting. :latest is rejected — Swarm compares the reference string, so an unchanged tag is a silent no-op. If the panel is behind Cloudflare Access, exempt this path or give CI a service token.

Autoscaler

Load is absorbed cheapest first: replicas in seconds, nodes in about two minutes. Coming down the order reverses — shed replicas first, remove the node later. The master is host #1, so with no workers it runs the app itself and nothing is billed; past 3 replicas the app moves entirely onto workers. Per-node capacity is measured from real CPU and RAM, not configured.

Replicas 6/8 ceiling 12
Hosts 4/5 master is #1 · floor 1 · ceiling 6
Placement Workers master carries no app replicas
Measured room 3  / 5 replicas per master / per new worker — from real CPU and RAM
SLO 500 ms the number everything derives from
Last loop just now runs every 60s
Scaling up. The autoscaler wants 8 replicas and has 6. If that will not fit, it provisions a worker first.
