Storage

S3-compatible buckets — AWS, Backblaze, Hetzner Object Storage, a MinIO of your own. Defined once for the whole cluster; a database names one on its own Settings tab, so changing an endpoint is one edit here rather than an edit per database and the one you forgot.

Add a target

What a database's Settings tab will refer to. Not renameable.

Blank for AWS. Anything else needs its own URL, and it should be https — what travels over it is the whole database.

Optional. Each database gets its own folder under this.

Stored as a Swarm secret, never in a file the panel writes — a backup agent runs on whichever machine holds the database, and Swarm is the only thing that can put a credential there.

On by default. It costs nothing on any implementation that supports it, and what is in the bucket is every row of your database.

Credentials are written first: a target pointing at a secret that does not exist is a database that fails to deploy with a message about Swarm rather than about storage.
