active schedules normally. pause keeps what is running and accepts nothing new. drain moves every task off and keeps it off — which on the master means the whole control plane's workload relocates, and at MIN_WORKERS=0 there is nowhere for it to go.

The autoscaler drains a worker itself when it is deleting it. Draining one here does not delete the server, and it does not stop the autoscaler counting the node as fleet capacity it may still be sizing against.
