The two rings on each node are reserved capacity, not usage. A full ring means every core or byte on that machine is already promised to something, and no further replica can be placed there however idle it looks — a node routinely reads 4% busy while being 100% reserved. This is the pair the autoscaler buys and deletes servers on.
