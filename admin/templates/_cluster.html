cpu · mem · disk

The three bars on each node are CPU, memory and disk. The fill is what the machine is using; the mark across it is what has been reserved — and it is reservation, not usage, that decides whether another replica can be placed here. A node routinely reads 4% busy while being 100% reserved and able to take nothing more, which is why the two are drawn on one scale rather than in two places. This is the pair the autoscaler buys and deletes servers on. Disk has no mark: Swarm has no disk reservation.
